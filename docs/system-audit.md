# Consultar la auditoría del sistema

Entra con el rol **Administrador del sistema** y abre **Sistema → Auditoría
del sistema**. La lista muestra primero los cambios más recientes. Usa **Tipo
de acción** para buscar una precarga creada o cancelada, un cambio de roles,
una activación, una desactivación o una eliminación de cuenta.

La columna **Realizado por** identifica a la cuenta que hizo el cambio. La
columna **Cuenta o precarga afectada** muestra la referencia del registro
afectado. Si una cuenta ya fue eliminada o el evento corresponde a una
precarga, verás su identificador. Las fechas se muestran en hora de Chile.

La bitácora comienza a registrar estos cambios desde que se habilita la
funcionalidad. Los cambios anteriores no se reconstruyen.
